# JIG Standalone — Downloads

Installers and update metadata for **JIG Standalone** (Jig & Toolings Management System, single-computer edition) by Aura Studio.

- Download the latest installer from [Releases](../../releases/latest): Windows `.msi`, macOS `.dmg`.
- A 30-day trial starts automatically on first launch. A license file is required afterwards.
- `version.json` is read by the app's "Check for Updates" screen.

This repository contains no application source code.
